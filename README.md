# Personality Compatibility and Collaboration: A MBTI-Based Approach to Actor Relationships

> Exploring the relationship between actors' MBTI personality types and their professional relationships.

---

## Project Description

This project aims to answer the following question: **Is there a relationship between an actor's MBTI personality type and their relationships with other actors?**

The analysis is divided into three main steps, each corresponding to a dedicated notebook: individual exploration of the two databases, followed by their integration and cross-analysis.

## Notebooks

### `datatest.ipynb` — Actors Database Analysis

Exploration and cleaning of the [Kaggle](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata) dataset containing information about actors and movies.

### `mbti.ipynb` — MBTI Database Analysis

Exploration of the [Kaggle](https://www.kaggle.com/datasets/yuraslastya/celeb-mbti) dataset containing celebrities and their MBTI personality types.

### `graph.ipynb` — Database Merging & Relationship Analysis

Merging of the two datasets and investigation of potential relationships between actors' MBTI personality types and their professional relationships. This notebook covers:

- Data merging and cleaning
- Homophily
- Heterophily
